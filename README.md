His battery is at one percent and he never charged it, so the phone does the talking itself. It spends its last seconds passing on the stuff that actually matters day to day: an apology owed since tuesday, where the spare key lives, and a warning about the dog, who has already eaten twice and will absolutely try for a third. `main.ts` writes that one text to `/output/entry.txt`, the same words every run, nothing fetched or randomised. It checks the line fits the rules first (one line, 1 to 200 characters) and reads the file back after writing.

The line: "hey, this is his phone, i'm at 1% and going dark, so quick: tell maya he's sorry about tuesday, the spare key is under the blue pot, and the dog already ate twice today, no third dinner"

## Run it

```sh
node main.ts
```

That writes the line to `/output/entry.txt`. Needs Node 22.18 or later (the grader runs Node 22.23.4).
